# Flying-Engineer
飛翔工程行 React + TSX

## 技術棧 (Tech Stack)

- **React** (create-react-app with TypeScript template)
- **MUI** (@mui/material) - UI component library
- **react-router-dom** - Client-side routing
- **react-spring** (@react-spring/web) - Animation library

## 開始使用 (Getting Started)

### 安裝依賴 (Install dependencies)
```bash
npm install
```

### 啟動開發伺服器 (Start development server)
```bash
npm start
```

### 建置 (Build)
```bash
npm run build
```

### 測試 (Test)
```bash
npm test
```
